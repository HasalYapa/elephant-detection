# Elephant Detection Backend

This is a Hugging Face Space that provides an API for elephant detection using YOLOv8.

## API Endpoints

### 1. /detect-image
Upload an image file for detection.

### 2. /detect-base64
Send a base64-encoded image for detection.

## Usage

See the API tab in the interface for usage examples.

## Model

This Space uses a YOLOv8 model trained to detect elephants.
